Cara Kerja Arsitektur Ini
  1. Cloudflare R2: Menyimpan file .pmtiles dengan gratis egress bandwidth ($0 transfer).
  2. GitHub Pages: Menyajikan web frontend ini (HTML/JS) secara statis.
  3. PMTiles Protocol: Browser melakukan HTTP Range Request langsung ke R2 hanya mengambil byte tile yang terlihat di viewport.
